# 统一SOP制作界面实施说明

状态：2026-10-16，按用户批准实施。已提供制作增量脚本，但未连接实际数据库执行。界面以KedaAdmin/src/views/sop/annotation/index.vue为参考，保留现有ElementUI样式与三栏结构。

## 业务关系

SOP制作就是SOP内容编辑，不再另建独立“标注对象”让项目再次关联。项目/子项目继续关联SOP的一个已发布revision_id，版本完整包含步骤、底图、操作指引和检测区域配置。

制作入口：SOP管理 → 新建/选择SOP → 选择草稿 → 进入统一制作界面。制作界面发布后提供“关联项目”按钮，选择有管理权限的项目或子项目，直接关联当前发布版本；项目详情的“关联SOP”作为另一个入口保留。两个入口复用同一关联接口和权限规则。可进入同版只读制作视图查看内容。有源编辑权限才允许进入源草稿编辑，不因使用关联获得源权限。

顶部显示管理项目（权限归属）、SOP编号/名称、版本状态，提供基本资料、保存草稿、预览和发布；已发布视图提供“关联项目”。管理项目与使用关联分别显示，不能切换顶部项目下拉就移动SOP归属。顶部不要求先选工位；后续执行阶段才绑定现场资源。

## 两种底图来源，一套标注编辑器

- 上传图片：选择PNG/JPEG → 校验 → 存入现有私有文件/步骤附件服务 → 选为当前底图。
- 摄像头（后续）：RTSP设备 → 采集服务预览 → 截图 → 确认/重拍 → 保存为固定图片 → 在图片上操作。画布不直接跟随实时视频变动。本批仅保留未接入状态入口，不建立连接。
- 摄像头窗口关闭或离开页面时停止本次预览资源；失败不制造占位截图或假成功。
- 同一步骤保留多张图片，沿用已有最多20张限制；每张独立标注，不强制每步只能一图。普通图文步骤可以没有检测区域。
- 更换底图新增文件与引用；明确提示原标注不能直接套用，不静默复用坐标。原文件在其他版本中的引用保留。

摄像头范围已由用户确认：后续使用RTSP，目前没有摄像头接入。本批只预留摄像头入口与来源信息扩展位置，显示“摄像头暂未接入”，截图按钮禁用；不收集或保存RTSP地址/密码，不创建摄像头连接/取帧接口，不恢复legacy采集代码，不生成模拟截图。当前以上传真实图片完成制作流程。RTSP后续通过采集服务提供预览及截图能力，具体对外接口待设备接入批次设计；本批不要求浏览器直接播放RTSP。

## 标注与检测配置

每个图片引用保存两组内容：

1. guide_items：矩形、箭头、文字，含稳定项ID、坐标、颜色、名称/文本和层级。
2. detection_regions：矩形区域、名称、启用标志、检测类型和相应参数（目标类别、置信阈值、期望数量、文字条件等）。参数按类型校验；没有接入模型时不显示“检测通过”。

两组可分别显示/隐藏。坐标相对于原图保存为0至1的比例，另存原图宽高及schema_version；字框、端点、区域边界均不得越界。检测类别使用可配置文本或后续模型提供的选项，不硬编码为螺丝/工件等行业类别。

参考画面与未来实时检测的镜头位置、方向、分辨率及裁剪范围必须匹配；摄像头来源记录和参考尺寸为后续校准提供依据。标注配置完成不等于实时识别/任务执行已实现。

## 数据设计草案

已有SOP、版本、步骤、文件、附件和项目/子项目关联表继续使用，原编号和版本不重建。

新增sop_step_visual一表，按attachment_id唯一关联某步骤的某图片引用：

| 字段组 | 内容 |
|---|---|
| 身份/引用 | id、attachment_id（唯一、外键） |
| 来源 | source_type（当前upload；camera_reference与captured_at随后续RTSP接入扩展） |
| 参考信息 | image_width、image_height、schema_version |
| 内容 | guide_items JSON、detection_regions JSON |
| 审计 | created_by、updated_by、created_at、updated_at |

不将标注挂在sop_file上：多个版本可以复用同一文件，各自的标注必须独立。camera_reference不存摄像头密码或带凭据URL。created_at等审计时间以服务端为准，客户端截图时间只作为来源信息。

sop_step补充等待时间和语音配置字段：detection_wait_seconds、voice_enabled、voice_text。现有instruction继续作为操作/文字引导，expected_duration_seconds继续表示参考作业时长，不拿它代替检测等待时间；precautions/check_requirements继续沿用。图片引导沿用现有附件，不重复存base64或外链。

现有图片没有visual行时按“无标注”读取，旧步骤新增字段提供兼容默认值；无需给旧记录编造区域或语音。正式迁移仅在审批后提供独立增量脚本，不重跑七表。

## 接口与版本保护

现有步骤增删改、排序、上传、发布、版本复制和项目关联接口继续复用。新增按SOP/版本/步骤/图片引用保存可视配置的接口；步骤请求扩展等待及语音字段，完整版本返回对应可视配置。最终URL与DTO随接口设计确认。

- 全部编辑限源管理项目编辑能力、可编辑项目和草稿状态；提交revision_version，使用既有聚合锁，保存后返回最新完整版本并递增版本计数。
- 保存草稿至少原子提交当前编辑单元（步骤配置及其当前底图标注），不出现标注成功而步骤配置静默失败。未保存切步骤/底图/离开时提示保存、放弃或取消，保存失败保留用户修改。
- 发布后步骤、底图、指引、检测区域及参数一起只读。发布检查JSON结构、坐标、文件可读及检测参数，不检查尚未接入模型的识别结果。
- 复制为新草稿时复制visual配置及步骤设置，分配新步骤、附件和可视配置记录；底层不可变图片可复用。修改新草稿不影响旧版。
- 项目使用方通过已有固定版本授权查看整套内容，含标注；没有源权限不能查看其他版本/草稿，不出现另一个项目标注绑定接口。
