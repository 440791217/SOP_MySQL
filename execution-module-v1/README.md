# 现场执行数据库

依赖已有用户、项目、SOP、资源模块表。在SQL客户端明确选择 sop_dev 后执行 schema.sql 全文，只新增三张表，不修改旧数据；已成功创建则无需重复执行。

- sop_execution：产品执行主记录、固定版本、内容JSON快照、状态、并发版本与工位占用。
- sop_execution_step：每步确认人和确认时间。
- sop_execution_event：开工、确认、暂停、恢复、完成、中止事件及原因。

permissions.sql 可选且可重复，定义现场操作员角色；root无需执行此文件。普通用户分配角色后，还必须是目标项目可见成员，重新登录以刷新权限。

同一任务同一产品码（区分大小写）不重复开工；中止后也不自动返工。同一工位只允许一笔未结束作业。结束数据不删除。内容快照留作追溯，图片仍保留原文件及版本引用。

完整规则及接口见 ../../SOP_Server_of_Java/docs/execution/README.md。H2测试通过不代表已操作或验证用户实际MySQL数据库。
